# 快速开始

MCU Live Watch Studio 用调试探针直接读写 Cortex-M 内存，适合在 MCU 持续运行时观察变量、调整参数和查看波形。它不是断点调试器，不提供单步、调用栈或反汇编。

## 准备内容

- 一个带 SWD/JTAG 调试接口的 Cortex-M 目标板。
- 一个 J-Link、ST-Link 或 DAPLink/CMSIS-DAP 探针。
- 带符号和 DWARF 调试信息的 ELF 或 AXF 文件。
- J-Link 模式需要安装 SEGGER J-Link Software；OpenOCD 模式可直接使用仓库的 `runtime/OpenOCD/bin/openocd.exe`。

如果只拿到 `.bin` 或 `.hex`，可以烧录，但无法按变量名解析结构体和全局变量；本软件的主要工作流应使用 `.elf` 或 `.axf`。

## 五分钟上手

1. 运行 `Mcu_Studio.exe`，或在源码目录执行 `python .\main.py`。
2. 在启动页选择深色或浅色主题，并选择当前固件的 ELF 或 AXF。
3. 选择后端：J-Link 使用“J-Link 原生驱动”；ST-Link/DAPLink 使用 OpenOCD。
4. 配置探针和芯片后，点击“连接并进入工作站”。
5. 在顶部输入已知变量名并点击“添加监视”，或打开“ELF 变量浏览器”搜索。
6. 在左侧变量表中右键标量，绑定到 CH1、CH2 或 CH3。
7. 右侧立即显示波形；按全局空格键暂停或继续显示。

## 工作站区域

- **顶部工具栏**：采样频率、快速添加变量、ELF 浏览器、断开、重连、烧录和复位。
- **左侧调试窗口**：三个固定变量页，显示变量、类型和约 5 Hz 实时值。
- **右侧实时波形**：三个多变量波形 CH、单图/双图/三图、暂停、适配、两点测量和 CSV 导出。
- **底部状态栏**：CH1–CH3 摘要、固定测量结果、连接状态和固定在右侧的烧录进度。

左右区域可拖动分割线调整宽度。三个通道卡片和烧录进度使用固定宽度，数值变长或调整左侧宽度时不会来回移动。

## 首次连接的安全顺序

1. 电机、功率电源、执行机构先禁能或断开负载。
2. 先验证“连接—读取—断开”，不要第一次就点击复位或烧录。
3. 确认变量值和类型正确后，再尝试写值。
4. 最后验证烧录和复位行为。

OpenOCD 的 target cfg 在初始化时可能复位或暂停目标；J-Link 普通读取不会主动发送复位，但“复位”和“烧录”按钮会改变目标运行状态。

## 常用操作

| 操作 | 方法 |
| --- | --- |
| 暂停/继续波形 | 全局按 `Space`，无论焦点在哪都只控制波形 |
| 删除变量组 | 在变量树选中根节点后按 `Delete`，或使用右键菜单 |
| 写入标量 | 双击“实时值”列，输入后按 Enter |
| 悬浮调试页 | 双击标签，或把标签拖出主窗口 |
| 恢复调试页 | 关闭悬浮窗口，标签自动回到原顺序 |
| 调整纵轴 | 点击波形右上角“适配” |
| 回看精确值 | 暂停波形后移动鼠标，查看十字光标和时间/数值 |

## 正常退出

直接关闭主窗口即可。程序会停止采样并释放后端；烧录或后台重连尚未结束时会阻止退出，避免中途破坏设备状态。
