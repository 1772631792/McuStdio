# 项目目录

## 根目录

根目录只保留必要入口和运行数据：

```text
McuStdio/
├─ live_set.py
├─ build.py
├─ live_watch_history.db
├─ README.md
├─ .gitignore
├─ assets/
├─ data/
├─ doc/
├─ dist/
├─ packaging/
├─ runtime/
├─ tools/
└─ artifacts/
```

- `live_set.py`：唯一的应用源码入口，PyInstaller 只打包这一个 Python 文件。
- `build.py`：打包入口。修改其顶部的 `APP_NAME` 可设置输出 EXE 名称；该文件不会被打入应用。
- `live_watch_history.db`：用户配置、变量和布局数据。源码运行时与 `live_set.py` 同级；打包后与 EXE 同级。
- `README.md`：项目介绍、安装、使用与打包说明。

## 分类目录

- `assets/`：图标等静态资源。
- `data/`：与当前运行数据无关的本地大型数据文件。
- `doc/`：项目文档和历史归档。
- `dist/`：打包成品目录，例如 `dist/Mcu_Studio.exe`；该目录被 Git 忽略。
- `packaging/`：当前唯一发布配置 `Mcu_Studio.spec`。
- `runtime/`：OpenOCD、ARM GCC、cfg 和 SVD。该目录不被 Git 忽略，应跟随开源仓库提交。
- `tools/`：图标生成和仓库打包辅助脚本。
- `artifacts/`：PyInstaller build 缓存和验证产物，均可重新生成。

## 打包输出

发布目录应为：

```text
dist/
├─ Mcu_Studio.exe
└─ live_watch_history.db
```

如果首次运行时没有 DB，程序会在 EXE 同级自动创建。

打包命令为 `python .\build.py`。成品位于项目根目录的 `dist/`，不要直接调用历史 spec。
