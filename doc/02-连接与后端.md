# 连接与后端

## 如何选择

| 探针 | 推荐模式 | 说明 |
| --- | --- | --- |
| SEGGER J-Link | J-Link 原生 | Windows 下最省事，使用官方 DLL 和驱动 |
| ST-Link | OpenOCD | 选择 `stlink.cfg` 和准确的 target cfg |
| DAPLink/CMSIS-DAP | OpenOCD | 选择 `cmsis-dap.cfg` 和准确的 target cfg |
| J-Link + OpenOCD | 一般不推荐 | 依赖 libusb，通常与 SEGGER 官方 Windows 驱动冲突 |

后端在配置页选择，进入工作站后点击左上角“返回配置”，即可重新选择后端再连接。

## ELF / AXF 文件要求

- 必须是当前目标板正在运行或准备烧录的固件对应 ELF 或 AXF；两者都按 ELF/DWARF 内容解析。
- 编译时应保留符号表和 DWARF 信息，通常是 GCC 的 `-g`。
- Release/LTO 可能删除变量或让变量没有稳定地址；需要长期观察的量可根据固件设计使用 `volatile`。
- ELF 被重新编译替换后，程序会等待文件稳定并标记为“待烧录”，但继续使用旧 ELF 映射调试仍在芯片中运行的旧固件；烧录成功后才自动切换符号和变量地址。

## J-Link 原生模式

J-Link 安装目录和 OpenOCD 程序均为可编辑下拉框。配置页打开时只加载数据库中已选择、曾经发现的有效路径和随程序工具，不会自动扫描电脑。点击“扫描电脑”后才会检查 PATH、注册表、常见安装位置和本机固定磁盘。新发现的安装会加入下拉框并缓存，可直接切换版本，不会覆盖当前有效选择。

1. 安装 SEGGER J-Link Software。
2. 在“J-Link 安装目录”选择安装根目录，通常是 `C:\Program Files\SEGGER\JLink`。
3. 点击“选择芯片”，按厂商或型号搜索并选择准确器件。
4. 点击“连接并进入工作站”。

程序会检查 Python/EXE 位数与 `JLink_x64.dll` 或 `JLinkARM.dll` 是否匹配。烧录时使用同一安装目录下的 `JLink.exe` 和器件 XML 中声明的 Flash loader。

### 器件选择注意事项

- 优先选择完整芯片型号，不要只选通用 `Cortex-Mx`。
- 扩展器件可能用通用内核名建立实时连接，但烧录仍使用所选器件的 Flash loader。
- 提示缺少 Flash loader 时，应安装包含该器件支持的新版 SEGGER 软件，而不是随便改成相似芯片。

## OpenOCD 模式

1. “OpenOCD 程序”可使用仓库内置的 `runtime/OpenOCD/bin/openocd.exe`。
2. 选择探针 interface：ST-Link 用 `stlink.cfg`，DAPLink 用 `cmsis-dap.cfg`。
3. 选择与芯片完全匹配的 target cfg。
4. 需要观察 OpenOCD 输出时，勾选“在独立窗口显示 OpenOCD 日志”。
5. 点击“连接并进入工作站”。

程序只开放本机回环地址的 TCL 端口 `6666`，并禁用不使用的 GDB/Telnet 端口。启动前会检查端口占用，连接后还会验证对端确实是 OpenOCD。

工作站的“返回配置”只释放当前采样和调试连接，不发送复位、暂停或烧录命令。再次从配置页连接 OpenOCD 属于一次新的后端初始化，是否触发复位仍取决于所选 target cfg。

### 自定义 cfg

下拉框只列出常用且实际存在的 cfg。列表没有目标时，使用右侧“浏览”选择厂商脚本。程序会自动把自定义 cfg 所在目录加入 OpenOCD 的脚本搜索路径，因此它可以继续引用同目录文件。

PY32、N32 等器件应使用厂商提供的 target cfg。某个 cfg 能加载不代表寄存器、Flash 和复位序列与目标芯片兼容。

## 断开与重连

- **延迟占用**：配置页只校验路径与 cfg，不启动 OpenOCD、不打开 J-Link；进入工作站并显示界面后才在后台建立连接。
- **断开**：停止软件读写并在后台释放当前后端，不主动烧录。
- **占用保护**：检测到 J-Link/OpenOCD 被其他下载或调试程序占用、进程退出或通信失败时，自动停止读写并释放后端，不会循环自动重连或重新抢占探针。
- **重连**：只能由用户手动触发。重新建立当前后端后，会读取一次磁盘上的最新 ELF/AXF，再恢复变量监视；OpenOCD 重连仍可能因 target cfg 而复位目标。
- **拔线后恢复**：先点击断开，恢复供电和接线，再点击重连。
- **切换探针/芯片/ELF**：点击“返回配置”安全释放当前连接，再重新配置。

标题栏 X 是紧急退出入口。即使 J-Link DLL 或后台重连没有返回，程序也会先停止自身任务、关闭套接字并终止自身启动的 OpenOCD，然后直接结束进程，不等待驱动线程。操作系统会回收仍被卡住的本进程原生句柄。

## 连接成功后的判断

- 底部状态显示“调试在线”并周期闪烁绿色状态点。
- 左侧变量能显示值，而不是“断开”。
- 绑定通道后，CH 卡片和右侧波形持续更新。

连接成功不等于变量一定正确；变量值明显异常时，应继续检查 ELF 是否对应当前固件、变量类型和地址是否正确。
