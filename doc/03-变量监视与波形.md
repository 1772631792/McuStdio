# 变量监视与波形

## 按名称或物理地址添加

### 已知变量名

在顶部“变量”输入框输入 ELF 中的全局变量名，选择类型后点击“添加监视”。如果 DWARF 中包含完整类型，结构体、数组和枚举会使用 ELF 类型信息，顶部类型选择主要用于缺少类型信息或物理地址场景。

### 已知物理地址

输入十六进制地址，例如 `0x20000100`，并选择实际类型：

- `uint8` / `int8`
- `uint16` / `int16`
- `uint32` / `int32` / `int`
- `float`

物理地址没有 ELF 类型保护。类型和宽度选错会得到错误值，写入时还可能覆盖相邻内存。

## 通过 ELF 变量浏览器添加

1. 点击“ELF 变量浏览器”。
2. 左侧源文件栏右上角可模糊筛选文件；留空时显示全部文件。
3. 顶部搜索框可模糊搜索变量名、类型或源文件；留空时不过滤变量。
4. 结构体与数组可以直接在浏览器中展开预览；双击成员仍会按完整根变量加入监视。
5. 双击变量或点击“添加到当前调试窗口”。添加后浏览器保持打开，可继续添加其他变量。
6. 需要指定窗口时，使用变量浏览器右键菜单选择主调试窗口、窗口 2 或窗口 3。

大型 ELF 的搜索结果单次最多显示 2000 项；完整符号仍然存在，继续输入关键字即可缩小范围。“重新提取当前 ELF”会重新读取符号表和 DWARF，并刷新已有变量结构。

三个调试窗口保存的是变量路径和窗口归属。程序启动、ELF 文件变化以及任一后端烧录完成后，都会根据当前 ELF 重新解析变量地址、成员偏移和类型；同名变量会自动跟随新的链接地址，变量或成员改名、删除后才会失效。物理地址监视不具备这种自动迁移能力。

## 结构体、数组、枚举和 static 变量

- 结构体和数组以树形展开，成员地址根据 DWARF 偏移计算。
- 数组最多展开 4096 个元素，类型递归深度最多 24 层，防止异常调试信息拖垮界面。
- 枚举读取时按底层整数解码；写值可输入枚举名或数值。
- 文件内 `static` 全局变量只要仍在符号表/DWARF 中并具有地址，就可以读取。
- 被优化掉、只存在寄存器中或被常量折叠的变量无法持续监视。

## 三个调试窗口

- 软件固定保留三个逻辑窗口，每个窗口独立保存监视变量。
- 同一变量可以出现在多个窗口；可见窗口的相同读取请求会去重，再把结果分发到各处。
- 双击标签或把标签拖出可形成悬浮窗口；关闭悬浮窗口会恢复原逻辑位置。
- 低速值约 5 Hz 刷新，只读取当前窗口和可见悬浮窗口中实际可见、已展开的标量。

## 写入变量

双击“实时值”列中的标量，输入新值并按 Enter。支持普通整数、浮点数、布尔/指针形式和带 DWARF 信息的枚举。

写入前确认：

1. ELF 与正在运行的固件一致。
2. 类型、符号和地址正确。
3. 目标变量允许在线修改。
4. 新值不会让控制器、功率级或执行机构进入危险状态。

结构体/数组容器本身不能直接写入，应展开后修改具体标量。写入不是事务操作，也没有自动回滚。

## 绑定高速通道

在变量树中右键一个标量，通过统一的“添加到波形通道”菜单绑定至 CH1、CH2 或 CH3。每个 CH 可以同时包含多个变量，同一个变量也可以显示在多个 CH；底层只采样一次，再把同一份数据分发到对应画布。

颜色属于变量曲线而不是 CH。新变量会从高对比调色板中自动选择尚未使用的颜色；在变量树或波形画布右键打开“曲线颜色”即可手动更换，选择结果会保存到数据库，下次绑定同一变量继续使用。

波形画布右键可以直接从三个调试窗口选择标量并加入当前 CH，也可以移除当前 CH 中的任意变量。右键菜单只保留软件自身功能，不再显示 pyqtgraph 的内部选项。单图、双图和三图只改变画布布局，不会销毁已有曲线或重复读取硬件。

## 采样频率

支持自定义频率和 500 Hz、1 kHz、2 kHz、4 kHz、8 kHz 预设。这里是目标频率，不是硬件保证值。实际速度取决于：

- 探针和 SWD 时钟。
- J-Link 或 OpenOCD 后端。
- 通道数量与数据宽度。
- 地址是否连续、是否非对齐。
- USB 延迟和目标状态。

## 波形操作

- **Space**：应用级全局快捷键，只暂停或继续波形显示；不会触发当前获得焦点的烧录、复位、重连等按钮，也不会在输入框插入空格。
- **暂停/继续**：与 Space 完全相同。暂停仅冻结显示，方便回看，不会把 Space 绑定到其他操作。
- **适配**：立即使用当前 5 秒时间窗内的缓存调整纵轴，不等待重新采样。
- **测量**：自动冻结当前波形，依次点击曲线上的两个点；点击会吸附到最近的真实采样点，两点之间只保留简洁连线，`Δt`（ms）和 `ΔY` 显示在底部固定测量栏，不遮挡曲线。第三次点击会开始下一次测量，退出测量模式会清除标记。
- **单图/双图/三图**：切换显示布局，现有曲线和十字光标对象会保留。
- **十字光标**：暂停后移动鼠标，显示相对时间和最近采样值。

横轴始终使用原始毫秒 `ms`，不会自动换成 `s` 或 `kms`。底部 CH1–CH3 卡片固定宽度：单变量时显示当前值，多变量时显示曲线数量，鼠标悬停可查看完整变量列表，不会把后续控件推来推去。

## 缓存与长时间运行

- 每个高速变量超过 40000 个采样点后回收至最近 25000 点。
- 绘图最多使用约 4000 个峰值保留点，避免高频曲线拖慢 GUI。
- CSV 使用完整的当前通道缓存快照，而不是屏幕降采样后的点。

## 导出 CSV

1. 至少绑定一个通道并采集到数据。
2. 在波形区域右键选择“导出采样 CSV”，或者在调试窗口中右键具体变量选择“导出该变量 CSV”。
3. 选择通道变量并确认数据范围。
4. 选择保存位置。

文件为 UTF-8 with BOM，第一列是 `time_ms`，第二列是变量名。打开导出窗口时会复制缓存快照，保存过程中实时采样继续运行；缓存以外的历史数据不会包含在文件中。
