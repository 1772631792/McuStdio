# 变量监视与波形

## 按名称或物理地址添加

### 已知变量名

在顶部“变量”输入框输入 ELF 中的全局变量名，选择类型后点击“添加监视”。如果 DWARF 中包含完整类型，结构体、数组和枚举会使用 ELF 类型信息，顶部类型选择主要用于缺少类型信息或物理地址场景。

### 已知物理地址

输入十六进制地址，例如 `0x20000100`，并选择实际类型：

- `uint8` / `int8`
- `uint16` / `int16`
- `uint32` / `int32` / `int`
- `float`

物理地址没有 ELF 类型保护。类型和宽度选错会得到错误值，写入时还可能覆盖相邻内存。

## 通过 ELF 变量浏览器添加

1. 点击“ELF 变量浏览器”。
2. 输入变量名关键字搜索。
3. 双击变量或点击“添加到当前调试窗口”。
4. 需要指定窗口时，使用变量浏览器右键菜单选择主调试窗口、窗口 2 或窗口 3。

大型 ELF 的搜索结果单次最多显示 2000 项；完整符号仍然存在，继续输入关键字即可缩小范围。“重新提取当前 ELF”会重新读取符号表和 DWARF，并刷新已有变量结构。

## 结构体、数组、枚举和 static 变量

- 结构体和数组以树形展开，成员地址根据 DWARF 偏移计算。
- 数组最多展开 4096 个元素，类型递归深度最多 24 层，防止异常调试信息拖垮界面。
- 枚举读取时按底层整数解码；写值可输入枚举名或数值。
- 文件内 `static` 全局变量只要仍在符号表/DWARF 中并具有地址，就可以读取。
- 被优化掉、只存在寄存器中或被常量折叠的变量无法持续监视。

## 三个调试窗口

- 软件固定保留三个逻辑窗口，每个窗口独立保存监视变量。
- 同一变量可以出现在多个窗口；可见窗口的相同读取请求会去重，再把结果分发到各处。
- 双击标签或把标签拖出可形成悬浮窗口；关闭悬浮窗口会恢复原逻辑位置。
- 低速值约 5 Hz 刷新，只读取当前窗口和可见悬浮窗口中实际可见、已展开的标量。

## 写入变量

双击“实时值”列中的标量，输入新值并按 Enter。支持普通整数、浮点数、布尔/指针形式和带 DWARF 信息的枚举。

写入前确认：

1. ELF 与正在运行的固件一致。
2. 类型、符号和地址正确。
3. 目标变量允许在线修改。
4. 新值不会让控制器、功率级或执行机构进入危险状态。

结构体/数组容器本身不能直接写入，应展开后修改具体标量。写入不是事务操作，也没有自动回滚。

## 绑定高速通道

在变量树中右键一个标量，绑定至 CH1、CH2 或 CH3。一个变量只绑定一个高速通道；重新绑定会解除旧通道。

波形画布右键可选择当前画布显示哪些已绑定通道，因此同一个通道可以显示在多个画布中。单图、双图和三图只改变画布布局，不会销毁已有曲线或重新读取硬件。

## 采样频率

支持自定义频率和 500 Hz、1 kHz、2 kHz、4 kHz、8 kHz 预设。这里是目标频率，不是硬件保证值。实际速度取决于：

- 探针和 SWD 时钟。
- J-Link 或 OpenOCD 后端。
- 通道数量与数据宽度。
- 地址是否连续、是否非对齐。
- USB 延迟和目标状态。

## 波形操作

- **Space**：应用级全局快捷键，只暂停或继续波形显示；不会触发当前获得焦点的烧录、复位、重连等按钮，也不会在输入框插入空格。
- **暂停/继续**：与 Space 完全相同。暂停仅冻结显示，方便回看，不会把 Space 绑定到其他操作。
- **适配**：立即使用当前 5 秒时间窗内的缓存调整纵轴，不等待重新采样。
- **单图/双图/三图**：切换显示布局，现有曲线和十字光标对象会保留。
- **十字光标**：暂停后移动鼠标，显示相对时间和最近采样值。

横轴始终使用原始毫秒 `ms`，不会自动换成 `s` 或 `kms`。底部 CH1–CH3 卡片固定宽度，负数或大数使用紧凑有效数字显示，不会把后续控件推来推去；鼠标悬停可查看完整变量路径。

## 缓存与长时间运行

- 每通道超过 40000 个采样点后回收至最近 25000 点。
- 绘图最多使用约 4000 个峰值保留点，避免高频曲线拖慢 GUI。
- CSV 使用完整的当前通道缓存快照，而不是屏幕降采样后的点。

## 导出 CSV

1. 至少绑定一个通道并采集到数据。
2. 点击波形工具栏的“导出 CSV”。
3. 选择通道变量并确认数据范围。
4. 选择保存位置。

文件为 UTF-8 with BOM，第一列是 `time_ms`，第二列是变量名。打开导出窗口时会复制缓存快照，保存过程中实时采样继续运行；缓存以外的历史数据不会包含在文件中。
