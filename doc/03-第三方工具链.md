# 第三方工具链

`runtime/` 是开源仓库的一部分，不应写入 `.gitignore`。该目录目前约为 1.14 GiB，包含约 8612 个文件。

## Arm GNU Toolchain

- 路径：`runtime/arm-gcc/`
- 发行版：Arm GNU Toolchain 15.2.Rel1
- GCC 版本：15.2.1
- 本地说明：`runtime/arm-gcc/share/doc/arm-none-eabi/readme.txt`
- GCC 授权文档：`runtime/arm-gcc/share/doc/gcc/Copying.html`
- GDB 授权文档：`runtime/arm-gcc/share/doc/gdb/Copying.html`
- 上游发布页：<https://developer.arm.com/downloads/-/arm-gnu-toolchain-downloads>

## OpenOCD

- 路径：`runtime/OpenOCD/`
- 版本：OpenOCD 0.12.0（2026-03-02 Sysprogs build）
- 程序声明：GNU GPL v2
- 上游项目：<https://github.com/openocd-org/openocd>
- 当前发行构建：<https://github.com/sysprogs/openocd>

OpenOCD 自带的 `interface/jlink.cfg` 通过 libusb 访问设备，不等同于程序的 SEGGER J-Link 原生后端。Windows 下安装官方 SEGGER 驱动时，优先使用原生后端；OpenOCD 建议搭配 ST-Link 或 DAPLink/CMSIS-DAP。

下拉框仅提供运行包中实际存在的常用 cfg。PY32、N32 等未内置型号应从芯片或开发板厂商获取匹配的 target cfg，再从界面浏览选择。

## 提交与发布注意事项

- `.gitattributes` 已将 `runtime/` 下的二进制文件标记为 `-text`，防止 Git 自动换行破坏 EXE、DLL 和库文件。
- cfg、Tcl、TXT、HTML 和 README 仍按文本文件管理。
- 不要删除工具链自带的许可证、README 和版权文件。
- 包含 GPL 二进制发布时，需要按对应许可证要求提供源码或有效的源码获取方式。
- 开源主项目的许可证不会自动替代第三方组件各自的许可证。
- 发布前运行 `python .\tools\validate_project.py`，并使用 `python .\build.py` 检查打包结果中只有 PyQt6 一套 Qt 绑定。

> 本文档是工程发布检查清单，不构成法律意见。正式发布前应再核对所采用的具体工具链发行包。
