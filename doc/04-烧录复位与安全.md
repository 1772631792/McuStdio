# 烧录、复位与安全

## 按钮含义

- **烧录**：把启动页选择的 ELF 写入目标 Flash，校验后复位运行。
- **复位**：立即复位并运行 MCU，执行前有确认提示。
- **断开**：停止采样并释放后端，不主动复位或烧录。
- **重连**：重新建立当前后端；OpenOCD 是否复位由 target cfg 决定。
- **返回配置/关闭程序**：停止采样、等待后台线程并释放连接，不主动发送复位、暂停或烧录命令。

烧录按钮当前没有二次确认。点击前必须确认 ELF、芯片和目标板正确。

## 烧录流程

### J-Link 原生

1. 暂停采样并释放当前 J-Link DLL 连接。
2. 使用 SEGGER 安装目录中的 `JLink.exe`。
3. 使用启动页选择的完整器件名和对应 Flash loader 烧录 ELF。
4. 校验并复位运行。
5. 重新加载 ELF 符号，恢复实时调试连接。

### OpenOCD

1. 停止采样并关闭当前 TCL 连接。
2. 停止由软件管理的 OpenOCD 调试实例。
3. 使用当前 interface/target cfg 执行 program、verify 和 reset run。
4. 烧录完成后重新启动 OpenOCD 调试后端。
5. 重新加载 ELF 符号，恢复实时监视。

两种后端都在后台线程完成烧录，界面不会因为外部工具等待而直接卡死。默认超时为 180 秒。

## 进度状态

底部右侧进度区固定显示烧录状态：

| 状态 | 含义 |
| --- | --- |
| `FLASH READY` | 当前没有烧录任务 |
| `PROGRAMMING` | 正在烧录或校验 |
| `DOWNLOAD OK` | 烧录、校验和基本恢复流程成功 |
| `DOWNLOAD FAILED` | 烧录失败，鼠标悬停查看详情 |
| 警告颜色 | 固件可能已烧录，但调试后端恢复失败 |

烧录或重连尚未结束时，程序会阻止直接关闭，避免在外部工具占用探针时强行退出。

## 高风险设备检查清单

在电机、逆变器、数字电源、加热器和其他执行机构上：

1. 先关闭功率输出或拆除负载。
2. 核对 ELF 构建时间、芯片型号和探针连接。
3. 确认启动代码在复位后不会立即驱动危险输出。
4. 首次烧录使用低风险板卡或台架电源限流。
5. 烧录期间不要拔探针、断电或强制结束程序。
6. 确认 `DOWNLOAD OK` 和底部重新在线后再恢复执行机构。

## OpenOCD 特别注意

- 连接、重连和烧录都会执行 target cfg 中定义的初始化序列。
- 错误的 cfg 可能导致错误复位、Flash 算法不匹配或目标失联。
- target cfg 必须来自芯片/开发板厂商或 OpenOCD 对该器件的明确支持，不能因为名字相近就混用。

## J-Link 特别注意

- J-Link 实时连接名和烧录器件名可能不同，软件会保留两者。
- 缺少 loader 时不要改成容量相近的其他型号，应安装正确器件包。
- 不要用 Zadig 替换正在供 J-Link 原生模式使用的 SEGGER 驱动。

## 失败后处理

1. 保持目标板供电，不要连续重复点击烧录。
2. 鼠标悬停底部失败状态查看具体信息。
3. 检查 ELF、Flash loader 或 OpenOCD cfg。
4. 点击断开，确认探针和目标供电，再尝试重连。
5. 必要时用厂商官方工具验证硬件链路和芯片是否可擦写。
