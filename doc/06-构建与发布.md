# 构建与发布

## 源码环境

建议使用 64 位 Python 3.10 或更高版本，并保证 Python 位数与 J-Link DLL 一致。

```powershell
python -m pip install PyQt6 pyqtgraph numpy pyelftools pylink-square pyinstaller
python .\main.py
```

## 构建前校验

以下命令不会连接探针或读写 MCU：

```powershell
python .\tools\validate_project.py
```

它会检查模块编译与导入、UI 行为、ELF/DWARF、OpenOCD 参数和解码、烧录工作线程、J-Link 配置、Qt 单绑定、图标及 Git 空白错误。

## 构建步骤

### 单文件版

1. 打开 `build.py`，按需修改顶部 `APP_NAME`，不要包含 `.exe`。
2. 运行：

```powershell
python .\build.py
```

3. 成品位于 `dist/<APP_NAME>.exe`，中间文件位于 `artifacts/build/`。

`build.py` 使用当前 `packaging/Mcu_Studio.spec`，固定收集 PyQt6，并排除 PySide6、PyQt5 等其他 Qt 绑定。构建结束后会检查 EXE 内容，发现多套 Qt 或缺少 PyQt6 时直接失败。

应用 PNG 图标会作为运行时资源打包，ICO 用于 Windows EXE。不要绕过 `build.py` 直接运行旧 spec；仓库已经不再保留历史 spec 副本。

### 内置 OpenOCD 的目录版

```powershell
python .\build_portable.py
```

成品位于 `dist/Mcu_Studio/`。该目录包含程序运行库、`runtime/OpenOCD/` 和 `data/`，发布时必须整体复制，不能只拿出 EXE。构建脚本会执行打包启动自检，并确认内置的 `openocd.exe` 存在。

## 发布内容

### 只面向 J-Link 用户

可以发布：

```text
Mcu_Studio.exe
```

用户电脑仍需安装 SEGGER J-Link Software。EXE 同级已有 `live_watch_history.db` 时会优先使用，否则在 `%LOCALAPPDATA%\McuStudio` 中创建。

### 需要内置 OpenOCD

运行 `build_portable.py` 会自动生成下面的完整结构：

```text
release/
├─ Mcu_Studio.exe
├─ portable-mode.flag
├─ data/
└─ runtime/
   └─ OpenOCD/
```

程序会优先从 EXE 同级的 `runtime/OpenOCD/bin/openocd.exe` 查找 OpenOCD。`portable-mode.flag` 会让数据库写入 `data/`，避免在发行目录根部出现 `live_watch_history.db-wal` 和 `live_watch_history.db-shm`。

V2.4 本地发布同时准备 `OpenOCD.zip`。把压缩包放在 `Mcu_Studio.exe` 同级并直接解压，得到 `OpenOCD/bin/openocd.exe` 后，程序可直接选择，无需手动创建 `runtime` 目录。

便携目录根部同时包含 `Create_Desktop_Shortcut.cmd`。双击后会在当前用户桌面创建名为 `Mcu_Studio` 的快捷方式，目标和工作目录均指向当前便携目录，不会复制或移动程序文件。

### V2.4 本地发布附件

```text
Mcu_Studio.exe           # 单文件版，J-Link 用户可单独下载
OpenOCD.zip              # 独立 OpenOCD 运行包
Mcu_Studio_Portable.zip  # 内置 OpenOCD 的完整目录版
```

### 携带预设配置

先关闭程序，再把选定的 `live_watch_history.db` 放到目录版的 `data/` 中；单文件版可放到 EXE 同级，程序会优先识别。公开发布通常不附带开发者本机 DB，避免暴露绝对路径。

## 发布检查清单

- `python .\tools\validate_project.py` 全部通过。
- 在干净目录启动最终 EXE。
- J-Link 或 OpenOCD 至少完成一次连接、读取、断开和重连。
- 烧录功能完成一次真实目标验证。
- 图标、主题和数据库创建正常。
- OpenOCD 发布包保留许可证、README 和源码获取说明。
- 生成 SHA-256 校验值：

```powershell
Get-FileHash .\dist\Mcu_Studio.exe -Algorithm SHA256
```

## Windows 提示与签名

未签名的个人工具可能出现 Defender SmartScreen“未知发布者”提示。自签名证书不能解决公共用户信任问题；需要消除发布者未知状态时，应使用受信任 CA 的 Authenticode 证书或 Microsoft Store。签名必须在构建完成后进行，签名后不能再修改 EXE。

## 第三方组件

- OpenOCD：GPL v2，当前仓库版本为 OpenOCD 0.12.0（Sysprogs 2026-03-02 build）。
- SEGGER J-Link：由用户安装，遵循 SEGGER 自身许可。
- PyQt6、pyqtgraph、numpy、pyelftools、pylink-square：发布前分别核对许可证要求。

本文只提供工程发布检查，不构成法律意见。
