# 构建与发布

## 源码环境

建议使用 64 位 Python 3.10 或更高版本，并保证 Python 位数与 J-Link DLL 一致。

```powershell
python -m pip install PyQt6 pyqtgraph numpy pyelftools pylink-square pyinstaller
python .\main.py
```

## 构建前校验

以下命令不会连接探针或读写 MCU：

```powershell
python .\tools\validate_project.py
```

它会检查模块编译与导入、UI 行为、ELF/DWARF、OpenOCD 参数和解码、烧录工作线程、J-Link 配置、Qt 单绑定、图标及 Git 空白错误。

## 构建步骤

1. 打开 `build.py`，按需修改顶部 `APP_NAME`，不要包含 `.exe`。
2. 运行：

```powershell
python .\build.py
```

3. 成品位于 `dist/<APP_NAME>.exe`，中间文件位于 `artifacts/build/`。

`build.py` 使用当前 `packaging/Mcu_Studio.spec`，固定收集 PyQt6，并排除 PySide6、PyQt5 等其他 Qt 绑定。构建结束后会检查 EXE 内容，发现多套 Qt 或缺少 PyQt6 时直接失败。

应用 PNG 图标会作为运行时资源打包，ICO 用于 Windows EXE。不要绕过 `build.py` 直接运行旧 spec；仓库已经不再保留历史 spec 副本。

## 发布内容

### 只面向 J-Link 用户

可以发布：

```text
Mcu_Studio.exe
```

用户电脑仍需安装 SEGGER J-Link Software。数据库会在 EXE 同级首次创建。

### 需要内置 OpenOCD

当前单文件 EXE 不包含整个 `runtime/OpenOCD` 目录。应按下面结构发布，或者让用户在启动页选择自己安装的 `openocd.exe`：

```text
release/
├─ Mcu_Studio.exe
└─ runtime/
   ├─ OpenOCD/
   ├─ cfg/
```

程序会优先从 EXE 同级或上级的 `runtime/OpenOCD/bin/openocd.exe` 查找 OpenOCD。

V2.1 Release 同时提供 `OpenOCD.zip`。把压缩包放在 `Mcu_Studio.exe` 同级并直接解压，得到 `OpenOCD/bin/openocd.exe` 后，程序可直接选择，无需手动创建 `runtime` 目录。

### V2.1 GitHub Release 附件

```text
Mcu_Studio.exe   # 主程序，J-Link 用户可单独下载
OpenOCD.zip      # ST-Link、CMSIS-DAP/DAPLink、OpenOCD 用户下载并解压
```

### 携带预设配置

先关闭程序，再把选定的 `live_watch_history.db` 放到 EXE 同级。公开发布通常不附带开发者本机 DB，避免暴露绝对路径。

## 发布检查清单

- `python .\tools\validate_project.py` 全部通过。
- 在干净目录启动最终 EXE。
- J-Link 或 OpenOCD 至少完成一次连接、读取、断开和重连。
- 烧录功能完成一次真实目标验证。
- 图标、主题和数据库创建正常。
- OpenOCD 发布包保留许可证、README 和源码获取说明。
- 生成 SHA-256 校验值：

```powershell
Get-FileHash .\dist\Mcu_Studio.exe -Algorithm SHA256
```

## Windows 提示与签名

未签名的个人工具可能出现 Defender SmartScreen“未知发布者”提示。自签名证书不能解决公共用户信任问题；需要消除发布者未知状态时，应使用受信任 CA 的 Authenticode 证书或 Microsoft Store。签名必须在构建完成后进行，签名后不能再修改 EXE。

## 第三方组件

- OpenOCD：GPL v2，当前仓库版本为 OpenOCD 0.12.0（Sysprogs 2026-03-02 build）。
- SEGGER J-Link：由用户安装，遵循 SEGGER 自身许可。
- PyQt6、pyqtgraph、numpy、pyelftools、pylink-square：发布前分别核对许可证要求。

本文只提供工程发布检查，不构成法律意见。
