# 故障排查

## 启动与数据库

### 无法创建 `live_watch_history.db`

- 确认 EXE 所在目录允许当前用户写入。
- 不要把便携版直接放进需要管理员权限的系统目录。
- 关闭其他可能长期占用 DB 的进程。
- 把旧 DB 改名后重试；先保留备份，不要直接删除。

### 配置路径全部失效

数据库保存的是绝对路径。移动工程、SEGGER 或 OpenOCD 后，在启动页重新浏览选择一次即可更新。

## ELF 与变量

### ELF 浏览器找不到变量

- 确认选择的是当前固件的 ELF，而不是 `.bin`/`.hex`。
- 编译时保留 `-g` 和 DWARF。
- 检查 Release/LTO 是否删除了未使用变量。
- 文件内 `static` 变量必须仍有稳定地址。
- 点击“重新提取当前 ELF”，或缩小搜索关键字。

### 值明显错误

- 确认 MCU 正在运行的固件与 ELF 一致。
- 物理地址模式检查类型、位宽和对齐。
- 检查变量是否为 union、packed 或被并发修改。
- 重新编译 ELF 后等待自动重载完成。

### 变量一直显示“断开”

- 查看底部后端状态。
- 先断开，再检查供电、SWD 接线和探针，最后重连。
- 确认目标没有进入低功耗模式或关闭调试端口。

## J-Link

### 找不到 DLL 或位数不匹配

- 选择 SEGGER 安装根目录。
- 64 位程序需要 64 位 J-Link DLL。
- 安装或升级官方 J-Link Software，不要从未知位置单独复制 DLL。

### 芯片能连接但不能烧录

- 选择完整器件型号，而不是通用 Cortex-M 内核。
- 检查提示中的 Flash loader 路径。
- 安装包含目标器件支持的新版 SEGGER 软件。
- 用 J-Link Commander 验证相同器件名和接线。

## OpenOCD

### `LIBUSB_ERROR_NOT_SUPPORTED` / `No J-Link device found`

OpenOCD J-Link adapter 需要 libusb，而 SEGGER 原生模式使用官方驱动。Windows 下建议直接切换到 J-Link 原生模式，或使用 ST-Link/DAPLink；不要随意用 Zadig 覆盖官方驱动。

### TCL 端口 6666 被占用

- 关闭遗留 OpenOCD 进程。
- 检查是否有其他程序使用 6666。
- 软件不会接管无法验证身份的旧端口服务。

### cfg 加载失败

- 检查 `openocd.exe`、interface cfg 和 target cfg 是否来自同一套脚本目录。
- 自定义 cfg 应从界面浏览选择，程序会加入对应搜索目录。
- 查看独立 OpenOCD 日志窗口的最后错误。

### 能连接但读值/烧录异常

- target cfg 可能不匹配芯片。
- 检查 transport、复位接线、Flash bank 和芯片保护位。
- 用厂商 OpenOCD 包或官方工具交叉验证。

## 波形与性能

### 设置 8 kHz 但达不到

预设值是目标速率。减少通道数、使用连续且对齐的地址、提高可用 SWD 速度，或优先使用 J-Link 原生后端。USB 和目标响应速度仍会限制实际值。

### 波形不更新

- 看按钮是否显示“继续”；显示“继续”表示当前处于暂停状态。
- 按一次 Space 或点击“继续”。
- 确认变量已经绑定到 CH1–CH3。
- 检查底部通道值和连接状态。

### 切换单图/多图后没有某条曲线

右键对应画布，确认该通道已勾选。布局切换只改变画布可见性，不会自动把所有通道放进每个画布。

### CSV 没有数据

必须先绑定通道并产生采样。导出窗口只保存打开窗口时的当前缓存快照，不包含已经被缓存上限淘汰的历史。

## 烧录

### 一直停在 `PROGRAMMING`

等待后台任务结束，默认最长约 180 秒。不要强制关闭或拔探针；超时后查看进度区提示，再检查外部工具是否能独立烧录。

### `DOWNLOAD OK` 后没有恢复在线

固件可能已经写入，但调试后端重启失败。确认 MCU 正常启动后，点击断开并手动重连。OpenOCD 模式重点检查 target cfg 和端口；J-Link 模式检查 USB 和器件名。

## 获取可用诊断

反馈问题时建议提供：

- 后端类型、探针和芯片型号。
- 软件提交版本或发布版本。
- ELF 编译器和优化级别。
- 完整错误文字或 OpenOCD 日志尾部。
- 能否用 J-Link Commander、STM32CubeProgrammer 或厂商工具连接。
- 问题发生在连接、读取、写值、重连还是烧录。

不要公开包含私有工程路径的数据库、完整固件或密钥。
