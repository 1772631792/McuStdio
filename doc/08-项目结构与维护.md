# 项目结构与维护

## 当前目录

```text
McuStdio/
├─ main.py                     # 源码入口
├─ build.py                    # 唯一打包入口
├─ Readme.md                   # 产品简介与快速说明
├─ mcu_studio/
│  ├─ __init__.py
│  ├─ core.py                  # 配置、SQLite、ELF/DWARF、OpenOCD 核心逻辑
│  ├─ workers.py               # 采样、读取、重连和烧录后台任务
│  └─ ui.py                    # 启动页、工作站、变量和波形交互
├─ assets/                     # 当前图标与界面截图
├─ packaging/Mcu_Studio.spec  # 当前唯一 PyInstaller spec
├─ runtime/
│  ├─ OpenOCD/                 # OpenOCD 运行包与许可证
│  ├─ cfg/                     # 附加配置
│  └─ svd/                     # 可选 SVD 资源
├─ tools/
│  ├─ validate_project.py      # 无硬件项目校验
│  ├─ make_icon.py
│  └─ pack-repo.ps1
├─ doc/                        # 当前文档
├─ dist/                       # 发布成品，Git 忽略
└─ artifacts/                  # 构建和预览产物，Git 忽略
```

`live_watch_history.db` 是本机运行状态，不属于源码；`data/*.db` 也被 Git 忽略。过时源码快照和历史 spec 不再放在 `doc/archive`，需要时从 Git 历史恢复。

## 模块职责

### `core.py`

- ELF 符号表和 DWARF 类型解析。
- 标量类型、结构体、数组和枚举地址计算。
- SQLite 配置与变量存储。
- OpenOCD 路径、cfg 校验、进程和 TCL 通信。
- J-Link DLL 位数和路径检查。
- J-Link/OpenOCD 共用的标量解码。

### `workers.py`

- 三通道高速采样。
- 可见变量低速批量读取。
- 后台后端关闭与重连。
- J-Link Commander 烧录。
- OpenOCD program/verify/reset 烧录与后端恢复。

### `ui.py`

- 启动配置和主题。
- J-Link 器件选择、ELF 浏览器和三个调试窗口。
- 变量写值、通道绑定、波形、CSV 和状态栏。
- 全局 Space、悬浮窗口和布局切换。

## 线程与稳定性原则

- GUI 线程只做界面更新，不执行可能长时间等待的硬件任务。
- J-Link 原生访问共享同一把锁，避免采样、表格和写入并发进入 DLL。
- 低速变量读取每次只允许一个批次，并合并多窗口的相同请求。
- 高频采样批量发送到 Qt，避免每个采样点产生一个事件。
- 缓存、绘图点数和 TCL 响应都有上限。
- 切换单图/多图只改变可见性，不清空和重建图元。
- 烧录、重连和后端释放在后台执行，未结束时阻止危险退出。

## 修改后的最低验证

任何代码修改后至少执行：

```powershell
python .\tools\validate_project.py
git diff --check
```

涉及硬件的修改还应按后端分别做真实测试：

1. 连接与持续读取。
2. 写入一个安全变量。
3. 三通道采样和布局切换。
4. 拔线/断电后的断开与重连。
5. 烧录、校验、复位和自动恢复。
6. 正常关闭与任务进行中关闭。

## 当前边界

- 不提供断点、单步、调用栈、反汇编和完整寄存器调试。
- 不保证所有探针/芯片组合达到设置的最高采样率。
- OpenOCD 初始化行为受 target cfg 控制，不能绝对保证不复位。
- 被编译器优化掉或没有稳定内存地址的变量无法读取。
- SVD 当前只是可选配置，不影响 ELF 变量、波形和烧录，也不提供完整寄存器视图。
- 软件没有无限历史记录；长期数据应主动导出 CSV。

## 后续优化优先级

保持小而完整，不扩展成 IDE。优先方向：

1. 显示实际采样率、失败次数和重连统计。
2. 增加有大小上限的本地诊断日志。
3. 完成 ST-Link/DAPLink 与常见 STM32 的实机矩阵。
4. 增加默认只读保护，显式解锁后才能写值、复位和烧录。
5. 按实际需求增加简单触发捕获和配置导入/导出。

不建议加入串口助手、RS-485、逻辑分析仪、复杂插件系统或任意停靠窗口；这些功能应保持为独立小工具。

## 第三方工具链维护

- `runtime/OpenOCD` 是仓库的一部分，不要删除其许可证和上游说明。
- 二进制文件由 `.gitattributes` 标记为 `-text`，避免换行转换损坏。
- 项目不需要捆绑 ARM GCC、GDB、NM、objdump 或 readelf；ELF/DWARF 由 `pyelftools` 解析。
- 更新 OpenOCD 后要重新运行项目校验，并至少实测一个 ST-Link 和一个 CMSIS-DAP 目标。
