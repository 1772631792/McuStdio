# 回归测试矩阵

V2.1 的自动回归由 `tools/regression_matrix.py` 执行，并由 `tools/validate_project.py` 统一调用。测试不连接真实调试器，也不会读写目标芯片。

## 覆盖范围

- 432 组用户流程组合：J-Link/OpenOCD 后端、连接状态、烧录状态、变量类型、滑动条状态及常见界面操作交叉组合。
- 68 组组件场景：数值边界、步进与范围自动扩展、多滑动条独立状态、写入请求合并、设备路径识别、线程退出和 SQLite 历史记录。
- 重点验证断开、重连、关闭窗口和后台任务停止时不会遗留活动线程，也不会因滑动条连续操作阻塞界面。

## 执行方式

```powershell
D:\python\python.exe .\tools\validate_project.py
```

校验成功时会报告 500 组组合测试通过，并继续执行源码编译、导入、数据库、打包配置和启动自检。

## 真实硬件建议

自动回归不会代替板卡验证。发布前建议至少使用一套 J-Link 和一套 OpenOCD 探针，分别检查连接、变量读取、变量写入、复位和烧录；高风险目标板应先确认供电、电平和 target cfg 完全匹配。
