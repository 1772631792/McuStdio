# 更新记录

## [2.1.0] - 2026-11-07

- 新增独立 FFT 频域显示、窗函数、基波搜索、H2–H30 谐波百分比和 THD。
- 新增频谱暂停悬停，显示频率、线性幅值、dBc 和谐波序号。
- J-Link/OpenOCD 改为可编辑路径下拉框，点击按钮后才执行后台全机扫描。
- 新增工作站安全返回配置，返回和关闭不会主动复位、暂停或烧录 MCU。
- 移除未使用的 SVD 配置与内置 SVD 资源，精简启动配置。
- 扩充无硬件回归，覆盖 FFT 数值、工具发现、句柄释放和返回配置流程。
