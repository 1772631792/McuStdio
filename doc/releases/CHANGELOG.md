# 更新记录

## [2.4.0] - 2026-11-13

- 配置页不再占用探针，工作站显示后才异步连接 J-Link/OpenOCD。
- 标题栏 X 不再等待重连或 J-Link DLL 返回，完成非阻塞资源释放后直接退出。
- 大变量树只读取可见顶层标量和已展开成员，并以 32 个变量为上限轮询。
- 顶层变量可在主窗口和悬浮调试窗口之间拖动；结构体成员可拖成独立调节项。

## [2.3.0] - 2026-11-12

- 固件选择器、变量解析和两种烧录后端支持 Keil `.axf` 文件。
- J-Link/OpenOCD 被其他下载或调试程序占用、进程退出或通信丢失时自动停止读写并释放后端。
- 移除高速采样线程的自动重连循环，断线后只允许用户手动重连，避免反复抢占探针。
- 手动重连成功后自动读取一次最新 ELF/AXF，再恢复变量监视和波形采样。

## [2.2.0] - 2026-11-09

- 多变量整宽滑动调节与独立参数保存。
- SQLite 后台采样历史和数据库/内存合并 CSV 导出。
- J-Link/OpenOCD 自动发现与双后端稳定性优化。
- ELF 浏览、波形测量、多变量通道、曲线图例和颜色持久化。
- OpenOCD/J-Link 烧录进度、校验、复位、断开和重连流程。
- 500 组组合回归、PyQt6 审计和最终 EXE 启动自检。
- 独立 FFT 频域显示、窗函数、基波搜索、H2–H30 谐波百分比和 THD。
- 频谱暂停悬停，显示频率、线性幅值、dBc 和谐波序号。
- J-Link/OpenOCD 可编辑路径下拉框和按需后台全机扫描。
- 工作站安全返回配置；返回和关闭不会主动复位、暂停或烧录 MCU。
- 单数据库多项目配置、主配置保护、配置新建/删除/清空以及历史隔离。
- 单文件版、独立 OpenOCD 包和内置 OpenOCD 目录版三种发布形式。
- 移除未使用的 SVD 配置与内置 SVD 资源，精简启动配置。
