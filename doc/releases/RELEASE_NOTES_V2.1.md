# MCU Live Watch Studio V2.1

V2.1 将 MCU Live Watch Studio 从实时变量示波器进一步扩展为时域、频域和在线调参一体化工具，同时改进调试工具发现、配置切换和关闭安全性。

## 主要更新

- 新增独立 FFT 频域模式：每个 CH 可分别选择时域或频域显示。
- 自动检测基波，显示 H2–H30 谐波相对基波百分比和 THD。
- 支持 Hann、Flat Top、Hamming、Blackman、矩形窗以及相干增益幅值校正。
- FFT 参数可设置分析点数、去直流、显示频率、基波搜索范围、谐波次数和峰值搜索宽度。
- 纵轴支持相对基波百分比、线性幅值和 dBc。
- 暂停频谱后可吸附普通频点、基波和谐波点，查看频率、百分比与线性幅值。
- J-Link/OpenOCD 路径改为可编辑下拉框；只有点击“扫描电脑”才进行后台固定磁盘扫描。
- 新增工作站返回配置按钮，安全停止采样、写入和连接后可重新选择后端与工具链。
- 返回配置或关闭程序不会主动发送 `reset`、`halt`、`program` 或烧录命令。
- 移除未使用的 SVD 输入和内置 SVD 文件，精简配置界面与发布内容。
- 一个数据库支持多套项目配置，固定主配置不可删除，并提供新建、删除和清空操作。
- 配置之间独立保存 ELF、后端、变量、滑动条、波形、布局和采样历史。
- 新增内置 OpenOCD 的目录版发布包，数据库集中存放在 `data/` 子目录。
- 单文件版优先读取 EXE 同级已有数据库；SQLite 正常运行只持久保留一个主 DB 文件。

## 下载和使用

### J-Link 原生模式

下载 `Mcu_Studio.exe`。电脑安装 SEGGER J-Link Software 后运行程序，在配置页选择 J-Link 安装目录和准确目标器件。

### OpenOCD 模式

同时下载 `Mcu_Studio.exe` 与 `OpenOCD.zip`，放在同一目录并直接解压为：

```text
OpenOCD/
└─ bin/openocd.exe
```

在配置页的 OpenOCD 下拉框中选择该程序；需要查找其他安装时点击“扫描电脑”。

也可以直接下载 `Mcu_Studio_Portable.zip`。它已经包含程序运行库和完整 OpenOCD，解压后运行目录中的 `Mcu_Studio.exe`，不要只复制其中一个 EXE。

## FFT 使用提示

在波形区域右键选择“显示模式 → 频域分析（FFT）”。默认 Hann 窗适合一般频谱观察，Flat Top 更适合幅值比较。建议把基波搜索范围限制在预期频段，避免强谐波被识别为基波。

FFT 适合近似稳态信号。实际采样率应高于待观察最高频率的两倍，并应积累足够的采样点以获得需要的频率分辨率。

## 安全说明

- 在线写变量前确认 ELF、变量类型、地址和设备状态。
- 返回配置和关闭程序只释放软件连接，不主动复位 MCU。
- 从配置页重新连接 OpenOCD 时，target cfg 的初始化行为仍可能复位目标。
- 烧录和手动复位属于明确的用户操作，功率设备应先进入安全状态。
