# MCU Live Watch Studio V2.4

V2.4 聚焦重连卡死时的退出可靠性、调试器占用时机、大变量列表性能和调试窗口之间的变量整理体验。

## 主要更新

- 配置页仅保存并校验 J-Link/OpenOCD 设置，不打开探针，也不启动 OpenOCD。
- 进入工作站且界面已经显示后，才通过后台线程连接 J-Link 或启动 OpenOCD。
- 标题栏 X 拥有最高退出优先级：不再因烧录/重连线程未结束而拒绝关闭。
- 退出时以非阻塞方式停止采样、写入和历史任务，关闭 TCL socket，终止本软件启动的 OpenOCD；不会调用可能永久阻塞的 J-Link `close()`。
- 低速变量表只读取当前可见的顶层标量和已展开容器中的可见叶子。
- 每轮最多读取 32 个低速变量，并使用轮询偏移保证大列表中的变量都能持续更新。
- 顶层变量可以在三个调试窗口之间拖动，窗口悬浮后仍可接收拖放。
- 结构体成员可以拖成独立顶层变量，保留原结构显示的同时便于直接打开滑动调节。
